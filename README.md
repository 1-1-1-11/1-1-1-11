我是徐俊毅，2027 届，做 **AI Agent 应用开发**。比起 demo 好不好看，我更在意东西能不能在客户现场真正跑起来——阶段产物看得见、不确定宁可停、交出去还能复核。

夏天在联界智能独立落地过 SEO 内容流水线和询盘背调：单篇从半天～一天压到大约十分钟；背调对不上身份就暂停，不让错的流进下游。写代码习惯先砍掉不必要的，再跟自己对着干一遍才交。

想看我实际做了什么，从这几个开始：

### [seo-content-workflow-demo](https://github.com/1-1-1-11/seo-content-workflow-demo) · SEO 内容流水线
关键词进，可发布草稿出。多 Agent 分阶段，产物可检查。这是脱敏公开版，mock 就能本地跑；生产实现不公开。

### [lead-verification-relay-demo](https://github.com/1-1-1-11/lead-verification-relay-demo) · 询盘背调 Relay
逐行核身份，对不上就停。自动化能快，但不能替人承担错判——所以默认停在可复核的地方。脱敏公开版。

<img src="assets/backcheck-dashboard-demo.png" alt="询盘背调运营总览" width="720" />

### [Proxy](https://github.com/1-1-1-11/Proxy) · CCBaga Proxy
Windows 上给 Claude 固定出口、做审计，并用专用浏览器门禁：出口 IP / WebRTC / DNS 不过检就不启动。给自己用的工具，要求是稳、可查。

### [RainScope](https://github.com/1-1-1-11/RainScope) · 雨境
暴雨数据可视化。Three.js / WebGL 粒子雨景，锚定郑州 7·20 等事实数据集——想把抽象数字做成能感觉到的雨。
